# Stage Stream

**Big idea:** Production pipeline strip placing tenders as connected stage blocks with actionable bottlenecks in high relief.

**Signature moves:** The Production Strip, Exception First Cards, Split Workbench.

**Borrowed from the reference:** Mint accent #3BE891, pill geometry, crisp technical borders, dark ink.

**Not borrowed:** name, product words, copy, images, logo, font files.

**Axes:** composition = command-centre board; emphasis = the work queue as hero; colour = neutral with a single accent; type = quiet grotesk with tabular numerals; density = dense operator view; chrome = side nav

## Critique

### Round 1
- First seen: The horizontal stage workflow strip.
- Template test: Clear pipeline operator view, avoids stock report look.
- Removed: Removed decorative stat cards to maximize vertical room for work queue.
- Tells: Addressed generic AI tell: avoided rounded cartoon cards, used crisp 4px borders.
- Changed: Added status indicators to the stage headers.

### Round 2
- First seen: Active queue cards with explicit action owners.
- Template test: Distinct purpose-built workflow tool for multi-team coordination.
- Removed: Kept secondary metadata compact to maintain high scanning velocity.
- Tells: Addressed tell warnings; color applied only on active stage border and pill badges.
- Mobile: Strip flex-wraps smoothly on mobile viewports.
