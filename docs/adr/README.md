# Architecture Decision Records

Record hard-to-reverse decisions here as numbered Markdown files:

```text
docs/adr/0001-short-title.md
docs/adr/0002-short-title.md
```

Each ADR contains status, date, context, decision, alternatives considered, and consequences. Update the index below when adding one.
